Inter (SIL Open Font License, see ../OFL-Inter.txt), Regular to Black, for the
stats share images. Made by make-fonts.py from Inter 4.0: only the characters
the images use, tabular digits in Inter-Black-Tnum, and Inter's kerning kept in
a classic 'kern' table (the font engine the app uses reads only that), so the
images match the designs drawn in a browser.

The ✦ star in the images is DejaVu Sans' U+2726 outline (Bitstream Vera
licence, free to use), drawn by the code in src/statshare.rs.
